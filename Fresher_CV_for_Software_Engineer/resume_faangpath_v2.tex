\begin{rSection}{Projects}

\projecttitle{SellWise --- AI Sales Analytics \& Inventory SaaS}{\sellwiseRepo}
\vspace{4pt}
\begin{itemize}
    \item Architected a multi-tenant retail SaaS with store-isolated data access, RBAC (Owner, Manager, Salesman), and ACID POS transactions across 4 sales channels using ASP.NET Core MVC, EF Core, and SQL Server 2022 (Docker).

    \item Designed RFM customer segmentation, expense tracking, and printable invoice generation to streamline retail analytics.

    \item Integrated a FastAPI + Meta Prophet microservice for 30-day demand forecasting from 90-day sales history with 24-hour Redis caching and EWMA fallback.

    \item Automated inventory Critical/Warning alerts with self-resolution on restock; generated on-demand sales, inventory, and audit PDF reports via QuestPDF.

    \item Seeded 2 demo stores with 180 days of synthetic sales data for end-to-end integration validation.

    \item {\bf Stack:}\\
    C\#, ASP.NET Core MVC, EF Core, SQL Server, Docker, Python, FastAPI, Meta Prophet, Bootstrap, Chart.js, QuestPDF.
\end{itemize}
